# 구현 결정

- 화면 톤은 SRS 8.3이 아니라 규정관리 시스템(흰 배경, 모서리 0, `#2f6fed`, SCoreDream)을 따른다.
- 저장소 루트는 `bojik/`가 아니라 이 폴더다.
- Drive 바로가기는 대상 파일·폴더로 푼다. 대상을 열 수 없으면 건너뛴다.
- 자료 폴더 ID와 발신 표시 이름·별칭은 Admin 운영 설정에서 Script Properties에 저장한다. 응답에는 폴더 ID 대신 폴더 이름만 준다.
- 메일은 Apps Script를 배포한 계정의 Gmail로만 나간다. 별칭은 그 계정에 등록된 주소만 허용한다.
- Admin 비밀번호는 Script Property `ADMIN_PASSWORD`다. 화면에서 처음 만들지 않는다.
- 받는 주소 도메인 `@yeonsung.ac.kr`은 고정이다.
- 자료 목록은 접속과 새로고침 때 받는다. 웹앱을 열면 동기화를 한 번 한다. 보직을 고르기 전에도 같다. 1분마다 다시 받는 것은 회의 10분 전부터 시작 1분 전까지다. 그 회의 날짜의 PDF 중 기기에 없거나 바뀐 것만 받아 둔다. PDF가 아닌 파일은 목록과 미리받기에 넣지 않는다. 목록 조회와 PDF 받기는 서버 대기열에서 한 번에 하나만 처리한다. 기기에 받아 둔 PDF는 저장한 지 90일이 지나면 앱을 열 때 지운다. 메모는 남긴다. 한 기기에서는 PDF를 한 번에 하나만 받고, 앞 파일이 끝난 뒤에 다음 파일을 받는다.
- 25MB 이하 첨부는 서버에 저장하지 않는다. 넘는 파일은 결과 폴더에 올리고 보관 일수 뒤 정리한다.
- 주소 확인은 발송 전 확인 화면 맨 위에 둔다.
- 메모 백업은 브라우저 저장소가 기본이고, Chromium PC는 사용자가 고른 폴더, 그 외에는 JSON 내려받기다.
- 운영 설정 조회는 `logs`의 `type: settings`로 한다. 저장은 `setConfig`다.
